# 阅本乐

剑桥英语培训机构的文字知识库，由 Codex 协助整理和使用。

## 使用方法

1. 将 Markdown 或 Word 文件放进 `00_待入库` 的对应目录。
2. 在 Codex 中打开本目录。
3. 对 Codex 说：`整理入库，并告诉我哪些信息需要人工确认。`

Codex 会复制保留原件、生成忠实 Markdown、整理知识文件并更新知识地图。待你核验后，再自行清理 `00_待入库` 中已处理的文件。详细规则见 `AGENTS.md`。

## 目录说明

- `00_待入库`：新资料入口。
- `01_原始资料`：分类保存的原始文件，不改写。
- `02_忠实转写`：便于全文检索的 Markdown 原文。
- `03_知识库`：经过整理、可供内容和方案生产使用的知识。
- `04_内容生产`：模板和正式成品。
- `05_知识地图`：Codex 和人员查找资料的入口。
- `90_历史归档`：废止、过期或不再使用的资料。
- `_系统`：入库记录和内部维护文件。

## 当前范围

只接收 `.md` 和 `.docx`。不需要 MinerU、Docling、向量数据库或 OpenAI API 密钥。
