# 外研思辨英语青少版 Think 0–2 总览

## 定位

本系列面向青少年英语学习者，以主题语境组织语言学习，并将语言功能、语法、词汇、阅读、写作、听力、发音、价值观、生活能力和思维训练结合。一级 1A/1B 现有 AI 整理稿，作为当前主要检索版本；入门级教师用书标注为 `Starter A1 / Second Edition`；其他级别的具体 CEFR 对应关系需要以机构课程标准或出版社官方资料再次确认。

这不是“只讲语法”的教材。它的基本教学单元包含：主题输入、语言聚焦、技能输出、`Train to THINK`、价值观/生活能力、文化页、练习与自测。

## 现有课程链路

| 课程段 | 册别 | 核心进阶 |
|---|---|---|
| 入门级 | A、B | 自我介绍、校园与日常沟通；从 be、指示词、一般现在时进入 can、现在进行时、过去时与比较级 |
| 一级 | 1A、1B | 从日常生活和基础过去时，进阶到义务/建议、过去进行时、将来表达、现在完成时和第一条件句 |
| 二级 | 2A、2B | 从现在完成时、比较与网络生活，进阶到未来形式、条件句、被动语态、过去完成时、间接引语与第三条件句 |

## 供 Codex 使用的原则

- 生产课程介绍时，先引用对应级别课程地图，明确写清册别与单元，而不是笼统声称“适合所有学生”。
- 设计教案时，按“主题 → 功能 → 语言 → 输入技能 → 输出任务 → 思维/价值”组织，不将语法练习孤立成唯一目标。
- 为家长或招生沟通制作内容时，优先解释可观察的学习产出：能完成的口头任务、写作任务、阅读/听力任务和项目/思维任务。
- 教材正文受版权保护；内容生产只引用必要的课程信息，不大段复刻课文、题目或答案。
