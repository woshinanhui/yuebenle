# Kid's Box New Generation Level 1 测评资源地图

## 资源组成

本批共 96 份测试资料：12 个单元测试、3 组阶段复习测试和 3 个期末测试。每项均有 B/E/S 三种版本，并配有含答案与无答案文件。当前保存为优化图文 Markdown；B/E/S 是原资料中的版本代码，本库不擅自解释其含义。

| 测试层级 | 覆盖范围 | 文件数 | 推荐用途 |
|---|---|---:|---|
| 单元测试 | Unit 1–12 | 72 | 单元结束检查、错题分析、补弱 |
| 阶段复习测试 | Unit 1–4、5–8、9–12 | 18 | 阶段复习、进度诊断 |
| 期末测试 | 全册 | 6 | 结课评估与教学复盘 |

## 使用规则

- 出卷、发给学生时优先使用无答案版；答案版仅供教师阅卷和教研分析。
- `01_原始资料/01_教材与教研/Kids_Box_New_Generation/Level_1_Tests_原始资料` 为 96 份优化图文 Markdown，适合 Codex 检索题型、词汇、语法点、答案信息及题图。
- 当前资料适合日常检索和教研使用；涉及图片细节或版式的内容，应以现有题图为准并进行人工复核。
- `02_忠实转写` 中的 Markdown 用于检索题型和文本；每份文件都标注原件图片数量，但不把图片题意臆测为文字。
- 目前没有从测试题推断机构的及格线、升班线、课时或年龄段；这些规则须由机构正式文件补充。
