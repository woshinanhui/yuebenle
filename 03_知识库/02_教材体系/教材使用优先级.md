# 教材使用优先级

## 产品线定位

| 教材系列 | 默认用途 | 不应直接推断 |
|---|---|---|
| Pippa and Pop BR1–3 | 低龄启蒙、故事共读、游戏与亲子活动 | CEFR、年龄、课时和升班标准 |
| Kid's Box New Generation Level 1–5 | 少儿综合英语、技能发展、剑桥少儿考试题型熟悉 | 机构成绩承诺和自动升班标准 |
| 外研思辨英语青少版 Think | 青少年综合英语、思辨、语言技能与项目任务 | 与 Kid's Box 的一一对应关系 |
| 沪教牛津版学校英语 | 校内同步、学情诊断、学校课程衔接 | Cambridge 课程等级和 CEFR |

## Codex 默认检索顺序

1. 先读 `03_知识库/02_教材体系` 中的系列总览或级别课程地图。
2. 需要教材内容时，优先读取 `02_AI整理稿` 或 `02_结构化整理稿`。
3. 需要核对原文、页码、题目、答案或 OCR 争议时，再读取 `01_原始OCR` 和 `01_原始资料`。
4. 普通教案、宣传和课程方案不得默认检索 `03_测试题转写` 中的答案文件。
5. 只有在出卷、阅卷、错题分析或测评设计任务中，才调用测试题；发给学生时优先使用 `answer_status: 无答案` 的版本。

## 冲突处理

- 整理稿与原始资料冲突时，以原始教材或教师用书为最终依据，并标记整理稿待修正。
- 教材说明与机构课程标准冲突时，教材只能说明内容范围；机构年龄、课时、价格、分班和升班规则以机构正式文件为准。
