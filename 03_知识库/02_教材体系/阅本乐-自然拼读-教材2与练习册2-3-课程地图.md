# 阅本乐自然拼读教材2与练习册2-3课程地图

## 资料定位

本资料是阅本乐内部自然拼读课程的“教材 2 + 配套练习册 2/3”图文资料。课程围绕 7 个 Lesson、42 个基础发音组织；教材提供故事导入、发音动作、词汇和口语输入，练习册用于听辨、拼读、书写、阅读及看图练习巩固。

## Codex 使用规则

- 需要某一发音、词汇或课堂活动时，先定位对应 Lesson，再阅读教材文件与两套练习册文件。
- 生成练习时可参考题型和词汇，但不得整页复制或当作机构正式测评标准。
- 对外介绍课程、制定课时或升班规则前，需补充并核对机构正式课程标准；本批资料未提供这些信息。
